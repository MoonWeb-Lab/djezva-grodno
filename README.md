# ☕ Кофейня-бистро «Джезва» — Мобильное веб-приложение (SPA)

> Мобильно-ориентированное веб-приложение для предзаказа «с собой» и доставки для кофейни-бистро **«Джезва»** (Гродно, ул. Советская, 5, Instagram: [@djezva_grodno](https://instagram.com/djezva_grodno)).

Стек технологий: **React 19 + TypeScript + Tailwind CSS v4 + Framer Motion + Lucide Icons + Canvas Confetti + Playwright E2E**.

---

## 📱 Особенности и возможности

1. **Mobile-First UX / Нативный опыт (390–430px):**
   - Hero-блок с зацикленным видео атмосферы кофейни (`public/videos/atmosphere.mp4`).
   - Закрепленная (sticky) панель категорий с плавающим пружинным индикатором `layoutId`.
   - Журнальные карточки (`MenuCard`) с акцентными бейджами, рекомендациями идеальных пар («Идеально с: ...») и капсулами веса/объема.
   - Компактные горизонтальные строки (`CompactMenuRow`) для позиций без фото — без пустых серых заглушек.

2. **Интерактивный конструктор напитков и блюд (`ItemCustomizerModal`):**
   - Выбор объёма (`180 мл` / `300 мл`).
   - Альтернативное молоко (овсяное, кокосовое, миндальное `+1.5 BYN`).
   - Натуральные сиропы (солёная карамель, лаванда, фундук, ваниль `+1.5 BYN`).
   - Дополнительные добавки к блюдам (домашняя сметана, сырный соус, луковый джем, пармезан `+1.5 BYN`).
   - Живой пересчет стоимости в реальном времени.

3. **Умная шторка корзины (`CartDrawer`):**
   - Переключатель: **«С собой (заберу сам)»** (точка: Гродно, ул. Советская, 5 с таймингом 10/20/30 мин или ко времени) и **«Доставка курьером»** (Яндекс Доставка по тарифу города без 30% комиссии агрегатора).
   - Строгая валидация белорусского номера телефона (`+375 (XX) XXX-XX-XX` с кодами операторов `29`, `33`, `44`, `25`).
   - Валидация имени гостя (от 2 символов) и адреса доставки.
   - Плавный фокус и скролл к первому ошибочному полю.

4. **Интеграция с Telegram Bot API (`src/services/telegram.ts`):**
   - Отправка структурированного чека с составом заказа, модификаторами и контактами гостя.
   - Бесшовный fallback в режим имитации (600 мс) при отсутствии токенов в `.env`.
   - Анимированный экран подтверждения с конфетти и номером заказа (`#DZ-XXXX`).

## 🚀 Запуск проекта

```bash
# Переход в папку проекта
cd C:\Users\user\.gemini\antigravity\scratch\djezva-grodno

# Запуск dev-сервера
npm run dev

# Проверка типов и сборка
npm run build

# Запуск E2E тестов Playwright
npm run test
```

---

## ⚙️ Настройка Telegram Bot API

Создайте файл `.env` в корне проекта (по образцу `.env.example`):
```env
VITE_TG_BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ
VITE_TG_CHAT_ID=-100123456789
```
*Если переменные не заданы, приложение работает в демонстрационном режиме без ошибок.*
